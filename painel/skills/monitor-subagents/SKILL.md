# Monitor Subagents Skill

Argumentos: $ARGUMENTS

Use esta skill para abrir e atualizar o painel de monitoramento de subagentes.

## Como usar
- Digite `/painel` no terminal para abrir o painel lateral.
- Acompanhe em tempo real o status de cada subagente ativo.
